# 三層級運費計算的優先順序與判定邏輯

## 金流系統判定鏈

1. **第一關（商品運費）：** 系統優先檢查好賣版商品頁面是否開啟「賣家吸收運費」。若設為 0 元，則判定為免運。
2. **第二關（賣場門檻）：** 若第一關未觸發，檢查訂單是否達到該賣場設定的「滿額免運」條件（例如：泡菜賣場滿 1,200 元免運）。
3. **第三關（系統預設）：** 若前兩關均未觸發，系統將回歸「金物流設定」，採用平台目前的預設價格（如 39 元）。

---

## 平台運費優惠補充

- 優惠期間內，買家訂單自動享有 $35 運費優惠。
- 此優惠**僅能在「物流設定」中開啟／關閉**。
- 若優惠期間中途關閉，下期將恢復賣家自訂的運費設定。
- 若賣場與商品同時設有免運門檻，以「**物流設定**」的門檻為準。
