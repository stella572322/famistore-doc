# 每月建立好賣+ 支付請求單

## 收取請款信件

每月初會收到優選寄來的信件，主旨格式：`好賣+ 20260602 請款單`

信件附件包含：

- `202605好賣+分潤.xlsx`
- `好賣+請款單260602.pdf`
- `發票列印_全網_一般_20260602.pdf`

## 檔案存放與準備

收到優選提供的支付單檔案後（系統維運費 + 藍新分潤），將檔案存放至：

```
\A_01_好賣+\07_發票開立\優選請款
```

- 發票印**兩份**，請款單列印**一份**
- 調整好賣+分潤 Excel 檔案格式，**新增寄件數總數的頁籤**，調整完成後進行列印
  - 範例：`A_01_好賣+\07_發票開立\優選請款\202406維運與分潤費用\優選提供\202405 好賣+分潤.xlsx`
- 檔案中的**藍新分潤頁籤也列印一份**

## Familynet 填寫支付請求單

- 支付請求單（**十萬以上授權總經理**）
- 支付類別：一般支付
- 對象代號：**C32004**
- 付款方式：匯款
- 勾選**內扣匯費**
- 需款日期：週二、週五、15 日、30/31 日（可設定下一週的日期，例如 6/9 申請可押 6/16）
- 說明：`11410好賣+系統維運費及藍新金流分潤費`

---

## 填寫憑證資訊

- 憑證區分：進項
- 憑證類別：電子發票
- 聯式：三聯
- 發票號碼：輸入紙本發票號碼（直接填英文+數字，不用 `-` dash）
- 憑證日期：輸入紙本發票開立日期
- 統一編號：**83057485**
- 費用區分：進貨及費用
- 課稅別：應稅
- 扣抵代號：直接扣抵

## 送出支付單

走支付單流程，附上前述所有資料後送出即可。

- 支付單範例：`A_01_好賣+\07_發票開立\優選請款\202407維運與分潤費用\支付單.pdf`

**合約參考：**

```
J:\09、公文管理\09-1、合約管理\112年合約\好賣+\
COVE230800027 優選互動科技股份有限公司 好賣+平台維運合作合約書
```

- 主約 → 增補 → 專案項目（運費變價）
- 11406 好賣+系統維運費及藍新金流分潤費，授權總經理
