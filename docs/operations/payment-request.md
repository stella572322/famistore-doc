# 每月建立好賣+ 支付請求單

## 全流程總覽

```mermaid
flowchart TD
    A["每月初收到優選請款信件<br/>（分潤 Excel＋請款單＋發票）"] --> B["檔案存放至<br/>07_發票開立\\優選請款"]
    B --> C["列印：發票兩份、請款單一份<br/>調整分潤 Excel（新增寄件數總數頁籤）<br/>藍新分潤頁籤也列印一份"]
    C --> D["Familynet 填寫支付請求單<br/>（十萬以上授權總經理）"]
    D --> E["填寫憑證資訊＋費用科目<br/>（維護費 6289／分潤 5106011）"]
    E --> F{當月第一次申請<br/>的新增費用？}
    F -- 是 --> G[附上相對應的合約]
    F -- 否 --> H[附上前述所有資料後送出]
    G --> H
```

## 收取請款信件

每月初會收到優選寄來的信件，主旨格式：`好賣+ 20260602 請款單`

信件附件包含：

- `202605好賣+分潤.xlsx`
- `好賣+請款單260602.pdf`
- `發票列印_全網_一般_20260602.pdf`

## 檔案存放與準備

收到優選提供的支付單檔案後（系統維運費 + 藍新分潤），將檔案存放至：

```
\A_01_好賣+\07_發票開立\優選請款
```

- 發票印**兩份**，請款單列印**一份**
- 調整好賣+分潤 Excel 檔案格式，**新增寄件數總數的頁籤**，調整完成後進行列印
  - 範例：`A_01_好賣+\07_發票開立\優選請款\202406維運與分潤費用\優選提供\202405 好賣+分潤.xlsx`
- 檔案中的**藍新分潤頁籤也列印一份**

- 勾選**內扣匯費**

## 送出支付單

走支付單流程，附上前述所有資料後送出即可。

- 支付單範例：`A_01_好賣+\07_發票開立\優選請款\202407維運與分潤費用\支付單.pdf`

**合約參考：**

```
J:\09、公文管理\09-1、合約管理\112年合約\好賣+\
COVE230800027 優選互動科技股份有限公司 好賣+平台維運合作合約書
```

- 主約 → 增補 → 專案項目（運費變價）
- 11406 好賣+系統維運費及藍新金流分潤費，授權總經理

:::info[第一次申請需附合約]
若是當月份**第一次申請的新增費用**，需要附上相對應的合約。各合約清單請見[合約主體與財務邏輯](../contract/)。
:::

### 專案維護費計算基準

依合約，追加專案維護費為「合約總額 × 10% ÷ 12」：

- **運費變價：** 880,000（未稅）× 10% ÷ 12 = **7,333 元/月**
- **首頁改版：** 首頁改版 150,000 + 新增開發項目 118,000 = 268,000（未稅）× 10% ÷ 12 = **2,233 元/月**

:::warning[金額勘誤]
原始筆記曾將首頁改版月維護費記為 22,333（268,000 ÷ 12），經確認應依 10% 年費規則計算為 **2,233 元/月**，與[月費支付時程](../contract/payment-schedule)一致。
:::
