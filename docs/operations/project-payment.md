# 好賣+ 專案開發支付請求單

針對專案開發項目（如行銷工具：折扣金改版）的分期請款流程。請款資料夾可參考「行銷工具第 X 期費用」。

:::info[第一次申請需附合約]
若是當月份**第一次申請的新增費用**，需要附上相對應的合約。例如專案維運費說明：主約 → 增補 → 專案項目（運費變價）。合約清單請見[合約主體與財務邏輯](../contract/)。
:::

## Familynet 填寫支付請求單

- 支付請求單
- 支付類別：一般支付
- 對象代號：**C32004**
- 付款方式：匯款
- 勾選**內扣匯費**
- 統一編號：**83057485**
- 需款日期：可以設定下一週的日期，例如 6/9 申請可押 6/16，確保跑完簽核流程後不延遲撥款時間
- 說明：`11506 行銷工具：折扣金改版-第二期款`（名稱可以參考上一期發票說明內容）

## 填寫憑證資訊

- 憑證區分：進項
- 憑證類別：電子發票
- 聯式：三聯
- 發票號碼：輸入紙本發票號碼（直接填英文+數字，不用 `-` dash）
- 憑證日期：輸入紙本發票開立日期
- 統一編號：**83057485**
- 費用區分：進貨及費用
- 課稅別：應稅
- 扣抵代號：直接扣抵
- 未稅金額：142,500（以第二期款為例）

## 費用科目

- 責任單位：**D130 資訊部**
- 科目代號：**2930**
- 科目名稱：**代收代付款項**
- 未稅金額：142,500

:::note
專案開發款項的科目代號為 **2930（代收代付款項）**，與維運費的 6289、分潤的 5106011 不同，請勿混用。
:::
