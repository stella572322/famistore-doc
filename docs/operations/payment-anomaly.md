# 貨態異常未撥款信件處理

當收到「貨態異常未撥款」信件時，依以下流程處理：

## 處理步驟

1. **上傳檔案：** 把信件附檔上傳至：

   ```
   A_01_好賣+\18_貨態異常未撥款
   ```

2. **重新命名：** 自行重新命名檔案，格式範例：`20260611 【好賣+】貨態異常未撥款圖`

3. **確認內容後回信**，回覆範例：

   > Dear XXX
   >
   > 確認完畢，再麻煩協助進行手動判賠方式匯款給賣家，謝謝!

![貨態異常未撥款信件範例](/img/haomaiplus/payment-anomaly-email.png)

## 背景說明

此情境對應[賠款與異常退款](../billing/claims)中的人工判定情境三：買家已完成取件，但好賣+ 貨態沒有更新，故無法正常匯款，需走人工匯款（手動判賠）。
