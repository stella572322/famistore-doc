# 好賣+ 知識庫

本知識庫涵蓋好賣家平台的架構邏輯、帳務金流機制、運費架構設計、合約與財務管理，以及日常營運 SOP。

## 目錄

| 類別 | 說明 |
|---|---|
| [平台介紹](./platform/) | 核心價值、雙版本架構（好賣版 vs. 超賣版）、賣場與後台設定、環境連結、買家端功能、帳號綁定機制 |
| [帳務與金流](./billing/) | 運費後扣機制、雙軌帳務時程、賠款退款、信用卡補扣、信用卡金流與退刷、60 天自動取消、藍新帳戶機制、匯款失敗處理 |
| [運費架構](./shipping/) | 三層級架構定義、計算優先順序、衝突處理原則、折抵金機制 |
| [合約與財務](./contract/) | 三方合約主體、維運費結算、月費時程、財務核對清單、物流 API |
| [營運 SOP](./operations/) | 每月宅配通對帳、好賣+支付請求單、專案開發支付單、貨態異常未撥款、賣場連結取得 |
| [已知問題](./issues/) | 短網址封鎖、寄件標籤異常、閉轉店 API 狀態不一致 |
