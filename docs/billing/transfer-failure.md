# 匯款失敗原因分析與帳戶修改流程

匯款失敗通常源於基礎資料不一致，導致銀行自動化核對失敗。

## 常見失敗原因

- 身分證字號與銀行戶名不符
- 銀行帳號輸入錯誤
- 修改資料後未點選儲存

## 帳差解讀

賣家若發現 1–2 元的微小**帳差 (Accounting Variance)**，通常屬銀行進位或匯費之「合理磨損」，無需恐慌。大額核對請以每月 5 號產出之「前一月總表」為準。

## 匯款失敗處置 SOP

```
匯款失敗狀態確認
  → 賣家至個人資料區修改正確銀行帳戶/戶名
  → 務必點選「儲存變更」
  → 系統驗證身分/銀行代碼
  → 下個帳期自動排入撥款流程（週四/五）
```

> **截單時限：** 若在指定截單日（通常為週三 23:59）前完成帳號更新，即可在當週的撥款日匯入新帳戶。
