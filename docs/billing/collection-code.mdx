# 代收代號與貨款動線

代收代號是好賣+ 與全家對帳的基本單位。同一筆常溫訂單在「寄」與「取」兩端各有自己的代號，但**只有取件端、且有代收款的那一條路才會產生帳**。

> 💡 **提醒**：本頁說明的是代收代號與其對應的貨款、運費動線；運費本身「後扣」的計算方式請見[運費後扣機制](./)。

## 常溫架構：寄 × 取 × 有無代收款

常溫的母代為 **148**，底下再分寄件端（線上／線下）與取件端（有／無代收款）：

| 路徑 | 代收代號 | 說明 | 有無帳 |
| --- | --- | --- | --- |
| ① 線上寄（網路印單） | `88I` | 寄件編號從網站取得 | ✕ 無帳，運費之後從代收款【後扣】 |
| ② 線下寄（店舖印單） | `KCU` | FamiPort 印好賣+寄件單 | ✕ 無帳，運費之後從代收款【後扣】 |
| ③ 取・有代收款（貨到付款） | `781` | 有貨款＝有代收款；冷凍取付同此代號 | ✓ **有帳** |
| 取・無代收款＝信用卡 | — | 取貨不付款，貨款不經店／全家 | ✕ 無帳，走宅配機制 |

:::info[為什麼「寄」沒有帳？]
寄件端的兩個代號（`88I`、`KCU`）都不經手金錢，運費是**之後從代收款「後扣」回來的**，所以全家端不會產生「寄」的帳。
:::

## 取貨付款金流：代收款與運費「後扣」
