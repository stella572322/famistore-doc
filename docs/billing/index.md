# 運費後扣機制與結算核心邏輯

平台採行「運費後扣」模式。

## 運作模式

根據系統後台邏輯，當訂單達成買家取貨之最終貨態時，系統會自動將運費轉化為賣家對平台的「應付款項」。

以店到店運費 39 元為例，撥款計算邏輯如下：

```
撥款金額 = (商品價值 $100 + 買家支付運費 $39) - 平台應扣運費 $39 = $100
```

---

## ACH 撥款方式說明

平台撥款給賣家採用 **ACH（批次代收代付，Automated Clearing House）** 轉帳方式。

賣家必須將姓名、身分證字號及收款銀行帳戶填寫完整，系統才能順利將款項匯入指定帳戶。

### 撥款週期

| 訂單取貨時間 | 待撥款查看時間 | 匯款時間 |
| --- | --- | --- |
| 週一～週三 | 當週五 | 下週二 |
| 週四～週日 | 下週三 | 下週四 |

> 💡 **提醒**：買家付款方式僅支援「貨到付款」或「信用卡」結帳，**沒有**提供「買家匯款/ATM 轉帳」的選項。
