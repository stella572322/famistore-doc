# 平台核心價值與運作邏輯

好賣家平台新手進駐全攻略：架構邏輯、版本選擇與營運實務。

- **流量與管理的分離：** 「**好賣市集**」與「**好賣家**」的差異。市集是面向消費者的購物入口，而好賣家則是賣家的管理後台。
- **買家即賣家的身分邏輯：** 平台的 C2C 主要以「單一 ID 手機號碼、雙重身分」運作。使用者無須切換帳號即可在消費者與經營者之間轉換。
- **核心受眾 (TA)：** 族群為 **40 歲左右女性**。
- **未來功能：** 平台將推動「**社區取 (Community Pickup)**」功能（如店到社區、社區到店、警衛室取貨）。
