# 好賣市集：買家下單與免運券

## 買家下單流程（含領券折抵）

買家於**好賣市集**下單，可於結帳時領券折抵運費。

> 💡 **提醒**：買家付款方式僅支援「貨到付款」或「信用卡」結帳，**沒有**提供「買家匯款/ATM 轉帳」的選項。

## 免運券使用提醒

1. 每日可折抵免運券數量有限，以「**先抵用先得**」原則。
2. 請務必於**領取當日 23:59 前**完成下單結帳。當日領取之優惠券需於當日使用完畢，可多次使用直至免運券數量使用完畢。
3. 領券後可至【會員中心】→【我的優惠券】查看。

## 賣家寄件流程（買家下單後）

```
買家下單 → 賣家取得寄件編號 → 賣家列印寄件標籤 → 包裹貼標後出貨
```

> 💡 **提醒**：寄件編號效期為 **14 天**，若賣家未於 14 天內出貨，寄件編號將失效，失效後可取消訂單或重新申請寄件編號。取得寄件編號**前**，賣家可自行取消訂單；取得寄件編號**後**，訂單即進入正式流程，買家無法單方面取消。
