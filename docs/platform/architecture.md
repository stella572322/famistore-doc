# 雙版本架構對比：好賣版 vs. 超賣版

「好賣版」與「超賣版」並存，並非功能迭代，而是源於早期 A、B 兩家技術廠商移轉過程中的歷史技術債，導致兩者在**資料庫 (DB) 結構**上有根本差異。

## 雙版本功能戰略對比表

| 比較項目 | 好賣版 (BC2C / 個人賣家) | 超賣版 (B2B2C / 品牌官網) |
| --- | --- | --- |
| **定位差異** | 適合快速開單、社群交易。 | 具備「官網概念」，適合大型品牌建立層級。 |
| **管理邏輯** | **多賣場概念**：一帳號可建多個獨立賣場，適合區分 FB/Line 不同客群。 | **單一官網分層**：所有商品需掛載於單一網頁下。 |
| **可設運費頁面** | 商品頁、賣場、金物流設定 | 商品頁、金物流設定 |
| **技術本質** | A 廠商開發 | B 廠商開發（基於原超級好賣版架構） |
